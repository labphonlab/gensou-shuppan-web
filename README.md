# 言叢出版 サイト

叢書「音声学ライブラリ」の案内とサポート情報。

- ビルド不要の静的サイト。GitHub Pages がそのまま配信する
- `dl/` は購入者向けの配布ファイル置き場。中身はパスワード付きZIPで、
  URLとパスワードは各書籍の巻末に記載する。`robots.txt` で索引から外している

## 構成

```
index.html                 トップ
onseigaku-library/         シリーズ紹介
support/                   動作環境・正誤表・更新履歴
dl/                        配布ZIP（パスワード保護）
assets/style.css           共通スタイル
```

配色と書体はカバーに合わせてある。叢書と版元のサイトが別物に見えないようにするため。
