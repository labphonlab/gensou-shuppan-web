# 言叢出版 サイト

叢書「音声学ライブラリ」の案内とサポート情報。

- ビルド不要の静的サイト。GitHub Pages がそのまま配信する
- 第1〜4巻のコードとNotebookは公開GitHubリポジトリの `main` を正本とし、刊行時点の固定版をGitHub Releaseで提供する
- `dl/` は購入者限定にする必要がある素材だけを置く。コードやNotebookと混在させず、パスワード付きZIPにする
- 旧版書籍が参照する一体型ZIPは後方互換のため残すが、新版の正本にはしない

## 構成

```
index.html                 トップ
onseigaku-library/         シリーズ紹介
support/                   動作環境・正誤表・更新履歴
dl/                        購入者限定素材ZIP・旧版互換ZIP
assets/style.css           共通スタイル
```

配色と書体はカバーに合わせてある。叢書と版元のサイトが別物に見えないようにするため。
